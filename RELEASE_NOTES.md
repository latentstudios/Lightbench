## What's new
- **Update notifications** — Lightbench now tells you when a new version is out (once a day, can be turned off).
- **Send Feedback / Report a Problem** in the Lightbench menu (top-left) — opens a pre-filled GitHub issue or email.
- **Welcome guide** for new users, reopenable from the Lightbench menu.
- If Lightbench ever crashes, it now offers to reload or report the problem.

## Installing
- **Windows:** download `Lightbench-Setup-win-x64.exe` and run it. If Windows shows "Windows protected your PC", click *More info → Run anyway*.
- **Mac:** download the `.dmg` for your Mac (Apple silicon or Intel), drag Lightbench into Applications, then right-click it and choose *Open* the first time.
